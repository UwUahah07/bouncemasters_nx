## 📖 О проекте

Этот репозиторий содержит **не саму игру Megabonk**, а файлы поддержки, необходимые для запуска её нативного порта на Nintendo Switch: загрузчик, слой совместимости с окружением Android/Unity, обработку ввода, графики, памяти и другие платформенные компоненты.

Репозиторий [`ChanseyIsTheBest/bouncemasters_nx`](https://github.com/ChanseyIsTheBest/bouncemasters_nx) использовался как источник подходящих файлов и наработок для поддержки запуска игры на Switch. **Это не порт Bouncemasters и не проект по переносу Bouncemasters.** Цель этой работы — Megabonk.

> [!NOTE]
> В исходниках и настройках могут оставаться старые названия, комментарии или идентификаторы от проектов, из которых переносились отдельные технические решения. Они не определяют назначение этого проекта и могут постепенно заменяться по мере развития порта.

В репозитории нет исходного кода Megabonk и нет игровых библиотек или ресурсов. Для запуска нужны соответствующие файлы игры, полученные пользователем самостоятельно и законным способом.

## 🧭 Что находится в репозитории

Проект сосредоточен на платформенной части запуска, в том числе:

- загрузке нативных библиотек игры;
- подготовке среды выполнения Unity/IL2CPP;
- адаптации необходимых Android API и JNI-вызовов;
- настройке графического пути Switch через GLES/EGL;
- обработке сенсорного ввода, кнопок и курсора;
- подготовке путей к ресурсам и пользовательским данным;
- настройке памяти, GPU-буферов и диагностики;
- сборке homebrew-приложения `.nro`.

Это вспомогательная инфраструктура для нативного порта, а не самостоятельный релиз игры или дистрибутив с игровыми файлами.

## 📦 Требования

### Для запуска

- Nintendo Switch с настроенной средой homebrew.
- Запуск в режиме **title override**. Для этого удерживайте `R` при запуске установленной игры.
- Собранный файл `.nro`.
- Совместимые библиотеки и ресурсы Megabonk, извлечённые из вашей собственной копии.

Порт требует больше памяти и системных разрешений, чем обычно дост��пно приложению в applet mode. Если приложение сообщает о нехватке памяти или необходимых системных вызовов, используйте title override.

### Для сборки

- devkitPro и devkitA64.
- Настроенная переменная `DEVKITPRO`.
- Switch portlibs:
  - `switch-mesa`
  - `switch-libdrm_nouveau`
  - `switch-sdl2`
  - `switch-zlib`
  - `switch-libpng`

Установка пакетов в Linux/macOS:

```bash
dkp-pacman -S switch-mesa switch-libdrm_nouveau switch-sdl2 switch-zlib switch-libpng
```

В Windows запустите команду из devkitPro MSYS2:

```bash
pacman -S switch-mesa switch-libdrm_nouveau switch-sdl2 switch-zlib switch-libpng
```

## 🔧 Сборка

Клонируйте репозиторий и перейдите в его каталог:

```bash
git clone https://github.com/UwUahah07/bouncemasters_nx.git
cd bouncemasters_nx
```

Задайте путь к devkitPro, если он ещё не настроен, и соберите проект:

```bash
export DEVKITPRO=/opt/devkitpro
make -j$(nproc)
```

Makefile собирает homebrew-приложение с именем `openbonk_nx.nro`. Для обычной сборки без параллелизма используйте `make`; для удаления результатов сборки — `make clean`.

> [!TIP]
> GitHub Actions также выполняет сборку при `push` и вручную через workflow. Готовый `.nro` публикуется как workflow artifact с именем `nro`.

### Проверка библиотек

Если в рабочем окружении присутствует `tools/symcheck.py`, можно запустить проверку staged-библиотек и таблиц импортов:

```bash
make check GAME=/путь/к/подготовленным/файлам
```

## 🚀 Подготовка и запуск

Сборка не включает игровые библиотеки или ресурсы. Подготовьте данные из собственной копии Megabonk и разместите их в каталоге, который обнаруживает загрузчик. В текущей конфигурации используются следующие имена библиотек:

```text
libmain.so
libunity.so
libil2cpp.so
```

Структура каталога с данными должна соответствовать ожиданиям текуще�� сборки и содержать необходимые Unity-файлы. Точный способ извлечения и состав файлов зависят от формата используемой версии игры; не распространяйте полученные игровые файлы.

Общий порядок:

1. Соберите `.nro`.
2. Скопируйте `.nro` на microSD-карту.
3. Подготовьте требуемые библиотеки и игровые ресурсы из собственной копии Megabonk.
4. Разместите их в доступном загрузчику каталоге, сохранив ожидаемые имена и структуру.
5. Запустите `.nro` через title override.
6. При проблеме проверьте сообщение на экране и `debug.log`, если диагностика включена.

> [!WARNING]
> Структура и имена каталогов могут меняться вместе с кодом загрузчика. Если запуск не проходит, ориентируйтесь на актуальные сообщения загрузчика и требования текущего commit, а не на примеры из старых сбор��к.

## 🕹️ Управление

По текущему состоянию проекта:

- **Меню:** касания или управление курсором.
- **В игре:** сенсорное управление и кнопки контроллера.
- **Курсор:** может управляться средствами ввода Switch, предусмотренными текущей сборкой.

Привязки не финальные и могут меняться. Если ввод перестал работать после обновления, укажите версию сборки и опишите используемый контроллер/режим в отчёте.

## 🧰 Настройка и диагностика

Большинство параметров сборки находится в `source/config.h`. Там настраиваются параметры диагностики, графики, аудио, ввода, памяти и совместимости.

Для диагностики предусмотрены флаги, включая:

- `DEBUG_LOG` — расширенный лог загрузки;
- `DEBUG_JNI_TRACE` — подробная трассировка JNI;
- `BM_LOG_BUTTONS` — события кнопок;
- `TRACE_IO` и `TRACE_MMAP` — подробная трассировка файлового ввода-вывода и отображения памяти.

Включайте только нужные флаги: подробное логирование может снизить производительность и увеличить количество записей на SD-карту. После сбора нужной информации верните их в исходное состояние.

### Если приложение сразу закрывается

1. Убедитесь, что используете title override, а не applet mode.
2. Проверьте, что `.nro` и требуемые данные доступны на карте памяти.
3. Проверьте совместимость файлов игры с текущей версией загрузчика.
4. Пересоберите проект после обновления исходников.
5. Сохраните `debug.log` и приложите его к отчёту о проблеме.

### Если нет звука

Отсутствие звука известно для текущего состояния порта. Это не обязательно означает ошибку установки; работа над аудиоподсистемой продолжается.

### Если наблюдаются вылеты или просадки FPS

Порт всё ещё в разработке. Для полезного отчёта укажите версию игры и сборки порта, режим запуска, режим консоли (handheld/docked), шаги для воспроизведения и лог.

bouncemasters_nx/
