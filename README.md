# Megabonk native (work in progress)

## Состояние порта

| Возможность | Статус |
|---|---|
| Игровой процесс | Запускается; возможны вылеты |
| Кнопка `B` в меню | Работает как отмена / возврат |
| `ZL` в игре | Работает как скольжение |
| `ZR` в игре | Работает как прыжок |
| `A` в игре | Работает как действие |
| Звук | Работает |
| Кнопка паузы | Не работает |
| Просмотр характеристик и процентов | Не работает |
| Производительность | Около 55 FPS; с просадками |
| Общая стабильность | Работа продолжается |

> [!WARNING]
> Порт экспериментальный. Некоторые действия пока не реализованы, а во время игры возможны нестабильная частота кадров, зависания и вылеты.
